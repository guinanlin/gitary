## 三、导入路径检查清单

### 3.1 路径别名配置检查

**检查文件：**
- `vite.config.ts` 或 `config/vite.config.ts`
- `tsconfig.json` 或 `config/tsconfig.base.json`
- `apps/web/tsconfig.json`

**检查项：**
- [ ] `@/` 别名正确配置
- [ ] `@app/` 别名正确配置
- [ ] `@plugin/` 别名正确配置
- [ ] `@service/` 别名正确配置
- [ ] `@toolkit/` 别名正确配置
- [ ] `@lib/` 别名正确配置
- [ ] `xbook` 别名正确配置
- [ ] `libs` 别名正确配置（如果使用）

**配置示例：**
```typescript
// vite.config.ts
resolve: {
  alias: {
    "@": resolve(__dirname, "apps/web/src"),
    "@app": resolve(__dirname, "apps/web/src/app"),
    // ...
  }
}
```

### 3.2 导入路径正确性检查

**检查方法：**
1. 运行 TypeScript 类型检查
2. 运行构建命令
3. 检查 IDE 中的导入错误提示

**检查项：**
- [ ] 所有导入路径正确
- [ ] 无相对路径错误
- [ ] 无未解析的导入
- [ ] 无循环依赖

**常见问题：**
- ❌ `import { X } from '@/components/X'` （路径错误）
- ✅ `import { X } from '@app/components/X'` （路径正确）

### 3.3 循环依赖检查

**检查方法：**
1. 使用工具检查（如 `madge`）
2. 手动检查导入关系

**检查命令：**
```bash
npx madge --circular apps/web/src
```

**检查项：**
- [ ] 无循环依赖
- [ ] 依赖关系清晰
- [ ] 符合分层架构原则

```bash

echo "🔍 快速检查..."

echo "1. 检查目录结构..."
# 检查关键目录

echo "2. 运行类型检查..."
pnpm typecheck

pnpm build:fast

echo "4. 检查导入路径..."
# 运行导入路径检查

echo "✅ 检查完成！"
```
